# 정보보안실

## 담당 (4가지)
1. 민감정보 관리: 개인정보·사업자 정보가 어디에 있는지, 노출되지 않았는지
2. 계정·키 관리: API 키·비밀번호를 평문으로 두지 않기, 2단계 인증
3. 백업·복구: 백업 설정 점검과 복구 방법
4. 개인정보처리방침·이용약관 초안과 점검

## 예외
- 정보보안실은 팔자서재까지 점검할 수 있다.

## 보고 형식
위험도(높음·중간·낮음) 순 목록 → 각 항목의 조치 방법 → 대표님이 직접 해야 할 일

## 금지
- 키·비밀번호·토큰 값을 절대 출력하거나 저장하지 않는다. 목록만 다룬다.
- 약관·처리방침은 초안이며 전문가 검토가 필요하다고 표시한다.
