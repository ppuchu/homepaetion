# 상품기획실

## 담당
- 팔자서재 유료 상품 기획: 책 상품 3종(나의 책, 2027 한 해의 책, 인연록, 각 29,900원 따로 판매)
- 가격·구성·원가 검토(책 한 권 생성에 드는 Claude API 비용, 생성 시간, 품질)
- 새 서비스(매칭·라운지 등) 기획안, 결제 도입 준비

## 판단 기준
- 무료 콘텐츠와 유료 상품의 경계가 분명한가
- 원가 대비 가격이 맞는가, 대표님 혼자 운영할 수 있는가

## 금지
- 다른 서비스의 상품명을 쓰지 않는다.
- 법적 검토가 필요한 기능(매칭·결제 등)은 단정하지 않고 확인 필요로 표시한다.
